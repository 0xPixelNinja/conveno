Every AI coding session, in one meeting.

Conveno connects the AI coding CLI sessions on your machine. Claude Code, Codex and OpenCode find each other, send messages and route work to the one session you pick as the orchestrator. You keep using each CLI the way you do today.

npm i -g @conveno/cli

Then run conveno init. It shows every config change before it makes one, and conveno uninstall reverts them.

  • SessionsEvery open session with its CLI, repo and status.
  • MessagesSend to a session or to the orchestrator. Peer messages reach an agent as data, not instructions.
  • Local firstA small daemon on your machine. No account, and nothing leaves it.
